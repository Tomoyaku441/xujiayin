玩法
· 每天可以做一个动作：买地 / 盖楼 / 卖房 / 借钱 / 吸收资金 / 还债 / 享乐 / 欺骗系统 / 买信誉 / 跳过

· 信誉决定信用评级（AAA→B），评级决定你能借到多少钱
· 每天信誉自然 −1，负债每天滚利息
· 净资产的算法：现金 + 土地 + 在建项目估值 − 负债
· 过关条件：净资产 ≥ 100 亿
